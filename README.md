***Simple Projects Management application***  


In the project management application, users can create projects, add members, and assign tasks.

It's an API application, the admin can : 

1- create project

2- update project

3- delete project

4- add member to project

5- create task

6- update task

7- delete task

8- assign task to member


And the member can:

1- show his projects

2- show his task

3- add comment on task

4- update comment


5- delete comment
